
树莓派python开发方式想象
```
┌──────────────────────────────┐
│        本地电脑（开发）       │
│                              │
│  venv → VS Code → git        │
│      │  ↑                   │
│      │ 类型提示（stub包）     │
│      ↓                       │
│  写代码 → 保存               │
└──────┬───────────────────────┘
       │ SFTP 同步
       ▼
┌──────────────────────────────┐
│        树莓派（运行）         │
│                              │
│  venv（真实包）               │
│      ↓                       │
│  SSH → python main.py        │
│      ↓                       │
│  控制硬件                     │
└──────────────────────────────┘



┌──────────────────────────────────────────────┐
│ 本地电脑（Windows / macOS / Linux）          │
│                                              │
│  Python venv (本地)                           │
│      ├── 安装 stub 包（types-RPi.GPIO 等）    │
│      └── 提供类型提示、补全、Lint             │
│                                              │
│  VS Code                                      │
│      ├── 代码补全、类型提示（来自本地 stub 包） │
│      └── Git（本地仓库）                      │
│                                              │
│  写代码 → 保存                                │
│      ↓                                        │
│  SFTP（FileZilla）                           │
│      ↓                                        │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 树莓派 Zero W（ARMv6）                        │
│                                              │
│  Python venv（树莓派）                        │
│      ├── 安装真实包（RPi.GPIO 等）            │
│      └── 负责实际运行                         │
│                                              │
│  接收来自本地的代码（SFTP）                    │
│                                              │
│  SSH 登录                                     │
│      ├── source venv/bin/activate             │
│      └── python main.py                       │
│                                              │
│  控制硬件（GPIO / I2C / SPI / 摄像头等）      │
└──────────────────────────────────────────────┘
```


```
树莓派中有python虚拟环境，装的是用于真实运行的包，如 RPi.GPIO
pip install RPi.GPIO

本地电脑也有python虚拟环境，但装的是仅仅用于代码补全类型的包（stub包）如 types-RPi.GPIO
pip install types-RPi.GPIO

在本地电脑编写完成代码后，就用 FileZilla（sftp）将代码上传至树莓派
然后ssh登录树莓派，来启动python代码
```


```
需要两个requirements文本文件
requirements.dev.txt
requirements.rpi.txt


本地电脑
requirements.dev.txt
pip freeze > requirements.dev.txt
pip install -r requirements.dev.txt

树莓派
requirements.rpi.txt
pip freeze > requirements.rpi.txt
pip install -r requirements.rpi.txt
```
