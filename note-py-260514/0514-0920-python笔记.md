```

[global]
proxy = http://127.0.0.1:10809

确认配置完成
pip config list

会看到类似：
```

```
配置自动格式化
.vscode/settings.json
```
```json
{
  // 针对 Python 文件的专属设置
  "[python]": {
    // 使用 Ruff 作为默认格式化器
    "editor.defaultFormatter": "charliermarsh.ruff",
    // 保存时自动格式化
    "editor.formatOnSave": true
  },
  // 启用 Ruff 的 lint（诊断提示）
  "ruff.lint.enable": true,
  // 不启用自动修复（fixAll），避免自动删除变量或 import
  "ruff.fixAll": false
}
```

验证 Ruff 是否生效，写一段乱格式的代码：
```python
import os,sys

def f( a,b ):
    return  a+ b
```
```
按 **Ctrl+S** 保存。应该看到：
- import 自动排序
- 空格自动修复
- 函数格式变成 Black 风格
- 未使用变量会提示
- 多余 import 会提示
```
